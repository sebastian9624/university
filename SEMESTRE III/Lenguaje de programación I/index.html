Fundamentos e historia de JavaScript

El primer navegador se llama NetScape y fue creado en 1994.

JavaScript es un lenguaje de programación que se utiliza principalmente para crear contenido interactivo en la web. Fue creado en 1995 pero en esos años se llamaba LiveScript por Brendan Eich mientras trabajaba en Netscape Communications Corporation. Un lenguaje básico de scripting. Es decir, un lenguaje de comandos especificos para hacer algunas cosas básicas. Desde entonces, ha evolucionado y se ha convertido en uno de los lenguajes de programación más populares del mundo.

En 1998, sale la segunda version de ECMAScript (actualizaciones de JavaScript).

JavaScript es un lenguaje que solo vive en el navegador.

En el año 2002 aparece un Libro llamado JavaScript: The Good Parts, de Douglas Crockford. Este libro es considerado una de las mejores referencias sobre JavaScript y ha influido en la forma en que se escribe el código en este lenguaje.

El único lenguaje que entienden los navegadores web es JavaScript.
